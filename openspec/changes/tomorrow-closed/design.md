# 设计

用户明确要求 React 与 Three.js：商店与剧情统一迁移为 React 组件；剧情使用类型化纯函数；Three.js 场景独立懒加载并清理 GPU 资源。无 WebGL 时显示静态城市，保留全部剧情。

有向场景图 + 类型化选择。选择包含条件、目标、状态变化和明确的后果文本。状态保存本局能力、剧情旗标、四位角色关系、牺牲能力及选择历史。关键选择改变下一个场景，汇合后仍保留前情：偷合同导致搜包、交出合同后不能再次出示；帮过司机才有专属接应；背弃承诺会在尾声中兑现。

浏览器存档只保存版本、能力 ID 和选择 ID 历史；恢复时从开场重放并验证每一步，不信任缓存金额、关系或任意文本。缓存损坏安全清理；存储不可用仍可游戏。已读场景不允许通过刷新改变历史。重开需确认。独立保存已达成结局图鉴，结尾可导出完整人生档案（能力、结局、关键选择、人物后续、未兑现承诺）。

界面使用独立剧情阅读区、幕次进度、人物关系、随身能力和可展开日志。键盘按钮可操作；切换场景聚焦标题；状态变化明确告知。手机不使用商店固定购物篮，避免遮挡剧情。轻动效尊重 reduced-motion。

剧情主线图：
开场 → 合作/偷窃/司机/管理处 → 对应后续 → 车站 → 已购能力事件/普通解法 → 心愿退货队 → 护送/证据/回家 → 档案馆 → 猫的不同反应/实习生 → 合约抉择 → 组合支线/普通信件 → 危机 → 有条件的角色接应 → 能力代价 → 最终抉择 → 8 结局与动态尾声。

GitHub Pages 维持纯静态。先做逻辑覆盖和浏览器双路线验证，之后推送 main。无法确认 Actions 结果时不得宣称线上已部署。

## 沉浸式体验修订（用户反馈）
取消剧情页的文章 + 表单布局与常驻侧栏。游戏全屏显示 Three.js 夜城，分幕切换建筑、列车、灯光与视角；底部采用逐段对话框，读完再给行动选择，可主动快进到决策。加入本地 SVG 人物立绘与叙事纸条。角色关系、能力、图鉴与日志放入原生 dialog 行囊，支持 Escape 关闭。提供场景射线点击观察与可键盘操作的“环顾四周”，观察不改变主线状态。减少动态效果时停止动画渲染；保留静态场景和全部文字交互。无 WebGL 和图形模块加载失败由静态兜底，不能阻断剧情。

# 把家搬到地球另一边

用同一条镜头把出发城市与对跖点连起来。视觉样片只做北京一站，在独立的 `/earth.html` 预览。主要场景用实拍地表底图、昼夜交界和薄暮大气，地下镜头采用简短的球体剖面示意。

1. 样片约五秒。先留住城市标记，推进到地表，展示穿越 12,742 公里的剖面，再从阿根廷内格罗河省拉远。观察手机上是否能看清落点与海岸的关系。提供重播、跳过与减少动效体验。
2. 样片评审后接入城市搜索与地球点选。用本地城市数据、坐标计算和可分享的 URL，支持任意经纬。
3. 增加海陆判断和最近海岸查询。先约定数据覆盖范围、精度及小岛缺失时的表述，再测海峡、群岛、极点和经度换日线。
4. 用多个地点检查镜头与结果。浏览器验证桌面、手机、减少动效与无 WebGL 后，再加入网站入口并发 GitHub Pages。

第一阶段依据画面判断是否继续。重点检查出发和抵达能否辨认、相机推进是否顺畅、地表占画面比例是否合适，以及手机上的标记和说明是否遮住地球。
